HEALTHCARE AGENTIC AI — MANUAL TESTING GUIDE

1. Enter Project & Configure Session
cd .\healthcare-agentic-ai

Set conservative session options once:
$env:PYTHONDONTWRITEBYTECODE = "1"
$env:HF_HUB_OFFLINE = "1"
$env:TRANSFORMERS_OFFLINE = "1"
$env:HF_HUB_DISABLE_TELEMETRY = "1"
$env:ANONYMIZED_TELEMETRY = "False"
$env:RUN_GPT_INTEGRATION = "0"

2. Run Offline Tests

Full test suite:
..\.venv\Scripts\python.exe -B -m unittest discover -s tests -t .

Focused final-decision tests:
..\.venv\Scripts\python.exe -B -m unittest tests.test_final_decision

3. Check Samples
..\.venv\Scripts\python.exe -B scripts\demo.py --list-samples

4. Check Local Retrieval
..\.venv\Scripts\python.exe -B scripts\demo.py --validate-only

5. Run One Live End-to-End Test
$run = "outputs\manual-test-$(Get-Date -Format 'yyyyMMdd-HHmmss-fff')"
..\.venv\Scripts\python.exe -B scripts\run_phase6.py --queries 1 --output-dir $run


Check exit code:
$LASTEXITCODE

6. Inspect & Verify the Run

View final decision:
Get-Content "$run\final_decision_001.json"

$decision = Get-Content "$run\final_decision_001.json" -Raw | ConvertFrom-Json
$decision | Select-Object status, workflow_status, proposal_withheld, human_review_required, review_state, safety_coverage

Verify without another cloud/model call:
..\.venv\Scripts\python.exe -B scripts\verify_amg_run.py "$run\sample_case_001.json" --final-decision "$run\final_decision_001.json"
